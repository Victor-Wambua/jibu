    How this demo works

    This page runs the real Jibu engine. It is not a mock-up and it does not call a server.

    Approach

    The repository’s own Python code runs in your browser under Pyodide (CPython compiled to WebAssembly). The runtime, the five libraries it needs and the engine are all files in this site; nothing is fetched from another host. Jibu uses no language model, so there is nothing to simulate: it is plain Python, a YAML knowledge base and BM25 scoring.

    What is real

    • Language detection, tokenising, Kiswahili and English stemming, spell-fixing, synonym groups, BM25 scoring, the confidence formula, the threshold and the hand-off, all from src/jibu.
    • The knowledge bases (kb/*.yaml) and the validator that checks them, with its line-numbered warnings.
    • Sessions (the last matched entry, used for follow-ups) and the hand-off queue, from the same service class the API uses.
    • The labelled question sets (eval/*.yaml) and every metric in the Evaluation view. The test demo/tests/smoke.spec.mjs checks that the page’s numbers equal what the command-line jibu eval prints.

    What is different or left out

    • There is no HTTP API, rate limiting, admin token, CORS, widget or WhatsApp webhook here. They are in the repository and have their own tests.
    • The token table in “Why this reply” is built by a small helper (demo/py/jibu_demo.py) that reads the engine’s own tables. A test checks that its coverage figure equals the engine’s.
    • Pyodide ships pydantic 2.10.5, PyYAML 6.0.2 and Python 3.12.7. The repository’s lock file pins newer pydantic and PyYAML. The evaluation numbers are identical either way.
    • Speed in your browser is not a benchmark of the real service.
    • The knowledge bases are fictional (a SACCO and a clinic). The evaluation was written by one person on synthetic data, so the figures are optimistic for real traffic. The README says more.

    Your data

    Questions are processed in this tab by code that has no network access. Nothing is saved to the browser except the files the page caches so it works offline after one visit. Reloading clears the conversation and the hand-off queue.

    Run the real thing

    From the README. Needs uv.

    git clone https://github.com/Victor-Wambua/jibu.git && cd jibu
uv sync
uv run jibu ask "Mnafungua saa ngapi?" --org umoja-sacco
uv run jibu eval
JIBU_DEFAULT_KB=umoja-sacco uv run jibu serve --port 4110
